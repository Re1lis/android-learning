# Переменные

## Коротко

Переменные хранят данные в программе. `val` - для значений, которые не меняются, `var` - для тех, что меняются, `const val` - для констант, значение которых известно уже при компиляции.

Объявление переменной: var или val (const val) + название переменной: тип переменной (необязательно, но желательно) = значение

## val
Неизменяемая переменная или переменная только для чтения
```kotlin
val age: Int
age = 23

// или сразу
val age: Int = 23
```

При изменении значения будет ошибка

## var
Переменная, значение которой можно многократно изменять
```kotlin
var name: String
name = "Lyoha"

// или сразу
var name: String = "Lyoha"
```

## const val
Константы менять нельзя (объявляется на самом верхнем уровне)
Если все переменные задаются в функциях, то этот вариант задается еще выше
```kotlin
const val maxAge = 120

fun main() // {}
```

> Разница между 'const val' и 'val':
> 1. Значение констант нельзя присвоить потом. Их значение должно быть присвоено сразу при объявлении
> 2. Значение val также нельзя изменить потом, но изначально ее можно определить, а потом уже задать ей значение
> 3. Значение констант должно быть известно до исполнения кода, то есть во время компиляции, тогда как значение val-переменных устанавливается во время выполнения
> 4. Const Val может иметь только простые (примитивные) типы данных: Int, Double, Boolean, String
