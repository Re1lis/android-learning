# Типы данных

## Коротко

У каждого значения в Kotlin есть тип: он определяет, сколько памяти занимает значение и какие операции с ним можно делать. Тип задается один раз и потом не меняется, а между типами значения переводятся только явно.

> Все компоненты программы в Kotlin, в том числе и переменные, представляют объекты, которые имеют определенный тип данных.
Тип данных определяет: какой значение в памяти и какие операции над ним можно производить.

## Целочисленные переменные

- Byte - хранит целое число от -128 до 127 и занимает 1 байт
- Short - хранит целое число от -32 768 до 32 767 и занимает 2 байта
- Int - хранит целое число от -2 147 483 648 до 2 147 483 647 и занимает 4 байта
- Long - хранит целое число от -2^63 до 2^63-1 и занимает 8 байт

```kotlin
val a: Byte = -10
val b: Short = 45
val c: Int = -250
val d: Long = 30000
```

> Целое число по умолчанию имеет тип Int. Если присвоить его переменной другого типа, оно преобразуется само, но только если влезает в диапазон: 127 в Byte можно, 128 уже ошибка

## Беззнаковые целочисленные

Хранят только положительные числа и ноль, поэтому верхняя граница в два раза больше

- UByte - хранит целое число от 0 до 255 и занимает 1 байт
- UShort - хранит целое число от 0 до 65 535 и занимает 2 байта
- UInt - хранит целое число от 0 до 2^32-1 и занимает 4 байта
- ULong - хранит целое число от 0 до 2^64-1 и занимает 8 байт

> [!NOTE]
> Обязательно надо ставить U в конце значения, так как без этого будет ошибка


## Суффиксы

Суффикс в конце числа подсказывает компилятору тип
```kotlin
val a: Long = 22L      // L - Long
val b: UByte = 10U     // U - беззнаковый тип
val c: Float = 3.14F   // F или f - Float
```

Какой тип получится с U:
- Если тип указан, U просто говорит что число беззнаковое, а конкретный тип берется из объявления
- Если тип не указан, будет UInt, а если число не влезает в UInt, то ULong
- Для UByte и UShort отдельной буквы нет, их можно получить только указав тип
- UL в конце - сразу ULong, даже для маленького числа

```kotlin
val a: UByte = 10U        // UByte, тип взят из объявления
val b: UByte = 300U       // ошибка: максимум у UByte 255
val c = 10U               // UInt
val d = 5_000_000_000U    // ULong: в UInt не влезает
val e = 10UL              // ULong
```

> Тот же принцип, что и у обычных целых: без суффикса Int, а если не влезает, то Long. С U вместо них UInt и ULong

## Другие системы счисления
```kotlin
val hex: Int = 0x0A1      // 0x - шестнадцатеричная, это 161
val bin: Int = 0b0101     // 0b - двоичная, это 5
```

Для читаемости разряды можно разделять подчеркиванием, на значение это не влияет
```kotlin
var million = 1_000_000
```

## Числа с плавающей точкой

- Float - хранит дробное число примерно от -3.4*10^38 до 3.4*10^38 и занимает 4 байта
- Double - хранит дробное число примерно от ±5.0*10^-324 до ±1.7*10^308 и занимает 8 байт



```kotlin
val height: Double = 1.78
val weight: Float = 65.5F   // без F будет ошибка

// экспоненциальная запись
val big: Double = 23e3      // 23000.0
val small: Double = 23e-3   // 0.023
```

> Дробная часть отделяется точкой, а не запятой. Float обязательно с суффиксом F, иначе число считается Double

## Boolean
Логический тип, хранит только true или false
```kotlin
val isAdult: Boolean = true
```

## Char
Хранит один символ в одинарных кавычках
```kotlin
val letter: Char = 'A'
```

Специальные символы задаются через обратный слэш: \t - табуляция, \n - перевод строки, \r - возврат каретки, \' и \" - кавычки, \\ - сам слэш

## String
Хранит строку в двойных кавычках
```kotlin
val name: String = "Lyoha"
val text: String = "Первая строка\nВторая строка"
```

Многострочная строка задается тройными кавычками, переносы и отступы сохраняются
```kotlin
val poem = """
    Строка раз
    Строка два
"""
```

Шаблоны строк: через знак доллара можно вставить значение переменной прямо в строку, через ${} целое выражение -
```kotlin
val firstName = "Lyoha"
val age = 23
println("Меня зовут $firstName, мне $age")
println("Через год мне будет ${age + 1}")
```

## Вывод типов

Тип можно не указывать, компилятор сам определит его по значению
```kotlin
val a = 5         // Int
val b = 5L        // Long
val c = 5U        // UInt
val d = 5.0       // Double
val e = 5.0F      // Float
val f = "Lyoha"   // String
```

> Если тип не указан, значение нужно присвоить сразу. Объявить переменную без типа и задать значение потом нельзя

## Статическая типизация

Тип переменной задается один раз и потом не меняется
```kotlin
var age = 23
age = "двадцать три"   // ошибка: age имеет тип Int
```

Значение одного типа нельзя просто так присвоить переменной другого типа, даже если оно влезает
```kotlin
val intN: Int = 10
val longN: Long = intN           // ошибка
val longN: Long = intN.toLong()  // так можно
```

Функции для преобразования: toByte(), toShort(), toInt(), toLong(), toFloat(), toDouble(), toChar()

> [!WARNING]
> При переводе дробного числа в целое дробная часть просто отбрасывается, округления нет

```kotlin
val a = 1267.5.toInt()     // 1267, а не 1268
val b = 3.99.toLong()      // 3
val c = (-3.7).toInt()     // -3, отбрасывание идет к нулю
```

> [!WARNING]
> Если число не влезает в тип поменьше, будет переполнение: получится совсем другое число и никакой ошибки

```kotlin
val d = 200.toByte() // -56, а не 127
```

## Тип Any

Может хранить значение любого типа
```kotlin
var anything: Any = "Lyoha"
anything = 23
```
