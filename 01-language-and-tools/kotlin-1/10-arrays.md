# Массивы

[← Диапазоны](09-ranges.md) · [Этап 1](../README.md) · [Главная](../../README.md)

## Коротко

Массив хранит набор значений **одного типа** под одним именем. Элементы нумеруются с нуля, доступ к ним идёт по индексу: `numbers[0]`. Размер массива задаётся при создании и дальше не меняется.

---

## Что такое массив

Раньше одно значение лежало в одной переменной. Если нужно хранить, например, оценки по пяти предметам, заводить пять переменных неудобно. Массив решает это: одно имя, много значений.

В Kotlin массив представлен типом `Array`, а тип элементов указывается в угловых скобках: `Array<Int>` — массив целых чисел, `Array<String>` — массив строк.

---

## Создание массива

### `arrayOf()`

Самый частый способ: перечисляем элементы в скобках.

```kotlin
val numbers: Array<Int> = arrayOf(1, 2, 3, 4, 5)
val people = arrayOf("Tom", "Bob", "Sam") // тип выводится сам
```

### `arrayOfNulls<T>(n)`

Создаёт массив из `n` элементов, и все они равны `null`. Заполнить его нужно позже.

```kotlin
val numbers = arrayOfNulls<Int>(3) // [null, null, null]
```

> [!WARNING]
> Тип такого массива — `Array<Int?>`, а не `Array<Int>`: ведь внутри лежит `null`. Про `?` и nullable-типы будет отдельный блок «Null safety», пока просто запомни, что `arrayOfNulls` даёт массив, который может содержать `null`.

### Конструктор `Array(size) { ... }`

Задаём размер и правило, по которому считается каждый элемент.

```kotlin
val numbers = Array(3, { 5 }) // [5, 5, 5]

var i = 1
val doubled = Array(3, { i++ * 2 }) // [2, 4, 6]
```

Во втором примере выражение в фигурных скобках выполняется для каждого элемента по очереди, и каждый раз `i` увеличивается на единицу (`i++` — вспомни пост- и префиксный инкремент из темы про операции с числами).

> [!NOTE]
> Фигурные скобки здесь — это лямбда-выражение, то есть «кусочек кода, который выполняется позже». Лямбды мы разберём отдельно, сейчас достаточно понимать так: «в скобках написано, как получить очередной элемент».

### Массивы для примитивных типов

Для базовых типов есть отдельные виды массивов: `IntArray`, `LongArray`, `DoubleArray`, `FloatArray`, `ShortArray`, `ByteArray`, `CharArray`, `BooleanArray`.

```kotlin
val numbers: IntArray = intArrayOf(1, 2, 3, 4, 5)
val doubles: DoubleArray = doubleArrayOf(2.4, 4.5, 1.2)

val fives = IntArray(3, { 5 })     // [5, 5, 5]
val ones = DoubleArray(3, { 1.5 }) // [1.5, 1.5, 1.5]
```

Чем они отличаются от `Array<Int>`: это более «лёгкие» массивы, они хранят числа напрямую и работают быстрее. Для обучения разница почти не видна, но в реальном коде для чисел принято брать `IntArray`, а не `Array<Int>`.

## Доступ по индексу и изменение

Индексация начинается **с нуля**. Индекс пишется в квадратных скобках. Элемент можно читать и переписывать.

```kotlin
val numbers = arrayOf(1, 2, 3, 4, 5)

val n = numbers[1]  // второй элемент
println(n)          // 2

numbers[2] = 7      // меняем третий элемент
println("numbers[2] = ${numbers[2]}") // numbers[2] = 7
```

> [!WARNING]
> Если обратиться к несуществующему индексу, программа упадёт с `ArrayIndexOutOfBoundsException`. В массиве из 5 элементов допустимы индексы от `0` до `4`, а `numbers[5]` — уже ошибка.
> ```kotlin
> val numbers = arrayOf(1, 2, 3, 4, 5)
> println(numbers[5]) // ArrayIndexOutOfBoundsException
> ```

> [!IMPORTANT]
> `val` у массива запрещает **переприсвоить** саму переменную (`numbers = arrayOf(9)` не скомпилируется), но не запрещает менять **содержимое**: `numbers[2] = 7` работает без проблем. Это тот же подвох, что и с `val` у изменяемых объектов в теме про переменные.

## Размер массива

Свойство `size` возвращает количество элементов.

```kotlin
val numbers = arrayOf(1, 2, 3, 4, 5)
println(numbers.size) // 5

val people = arrayOf("Tom", "Bob", "Sam")
println(people.size)  // 3
```

Последний допустимый индекс всегда равен `size - 1`.

> [!WARNING]
> Размер массива **нельзя изменить** после создания: ни добавить элемент, ни удалить. Если нужна коллекция, которая растёт и уменьшается, для этого есть `MutableList` — он у нас в плане чуть позже.

## Перебор элементов

### Простой перебор

Массив перебирается циклом `for`: переменная по очереди принимает значение каждого элемента.

```kotlin
val people = arrayOf("Tom", "Sam", "Bob")
for (person in people) {
    print("$person \t")
}
// Tom   Sam   Bob
```

### Перебор по индексам

Когда нужен и номер, и значение, здесь пригодятся диапазоны из прошлой темы. У массива есть свойство `indices` — диапазон всех допустимых индексов.

```kotlin
val people = arrayOf("Tom", "Sam", "Bob")

for (i in people.indices) {
    println("$i: ${people[i]}")
}
// 0: Tom
// 1: Sam
// 2: Bob
```

То же самое можно записать через `until`:

```kotlin
for (i in 0 until people.size) {
    println("$i: ${people[i]}")
}
```

> [!NOTE]
> Вот тот самый случай из темы про диапазоны, где `until` удобнее `..`: `0 until people.size` даёт ровно индексы `0..size - 1`. Если написать `0..people.size`, последний индекс выйдет за границы массива и программа упадёт.

### `withIndex()`

Ещё один способ получить индекс и значение сразу:

```kotlin
for ((index, person) in people.withIndex()) {
    println("$index: $person")
}
```

## Проверка наличия элемента

Операторы `in` и `!in` работают с массивами так же, как с диапазонами.

```kotlin
val numbers = arrayOf(1, 2, 3, 4, 5)

println(4 in numbers)  // true
println(2 !in numbers) // false
```

---

## Вывод массива

> [!WARNING]
> `println(numbers)` **не выведет** содержимое массива. Вместо `[1, 2, 3]` ты увидишь что-то вроде `[Ljava.lang.Integer;@1b6d3586` — это адрес объекта в памяти.
> ```kotlin
> val numbers = arrayOf(1, 2, 3)
> println(numbers)                    // [Ljava.lang.Integer;@1b6d3586
> println(numbers.contentToString()) // [1, 2, 3]
> ```
> Чтобы увидеть содержимое, используй `contentToString()`.

---

## Сравнение массивов

> [!WARNING]
> Оператор `==` для массивов сравнивает **ссылки**, а не содержимое. Два разных массива с одинаковыми элементами через `==` будут не равны.
> ```kotlin
> val a = arrayOf(1, 2, 3)
> val b = arrayOf(1, 2, 3)
> println(a == b)              // false
> println(a.contentEquals(b)) // true
> ```
> Для сравнения содержимого используй `contentEquals()`.

## Краткие итоги

| Что нужно | Как записать | Пример |
|---|---|---|
| Создать с элементами | `arrayOf(...)` | `arrayOf(1, 2, 3)` |
| Создать числовой | `intArrayOf(...)` | `intArrayOf(1, 2, 3)` |
| Создать пустой под `null` | `arrayOfNulls<T>(n)` | `arrayOfNulls<Int>(3)` |
| Создать по правилу | `Array(n) { ... }` | `Array(3) { 5 }` |
| Получить элемент | `a[i]` | `numbers[1]` |
| Изменить элемент | `a[i] = x` | `numbers[2] = 7` |
| Размер | `a.size` | `numbers.size` |
| Диапазон индексов | `a.indices` | `for (i in a.indices)` |
| Есть ли элемент | `in` / `!in` | `4 in numbers` |
| Вывести содержимое | `contentToString()` | `println(a.contentToString())` |

---

## Подвохи

1. **Индексы с нуля.** Последний элемент — `size - 1`, а не `size`.
2. **`numbers[size]` — это ошибка** `ArrayIndexOutOfBoundsException`, а не «пустое значение».
3. **Размер не меняется.** Нельзя добавить или удалить элемент, только заменить существующий.
4. **`val` не защищает содержимое.** Нельзя переприсвоить переменную, но элементы менять можно.
5. **`println(array)` печатает адрес**, а не элементы. Нужен `contentToString()`.
6. **`==` сравнивает ссылки.** Для содержимого нужен `contentEquals()`.
7. **`arrayOfNulls` даёт `Array<Int?>`**, а не `Array<Int>`.
