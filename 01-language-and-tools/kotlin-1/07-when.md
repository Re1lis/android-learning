# Конструкция when

[← if...else](06-if-else.md) · [Этап 1](../README.md) · [Главная](../../README.md)

## Коротко

when сравнивает значение с несколькими вариантами и выполняет ветку, которая подошла. Это удобная замена длинной цепочки if...else if. Как и if, when умеет возвращать значение.

## Базовая форма

В скобках после when - значение, которое проверяем. Дальше ветки вида `вариант -> что сделать`
```kotlin
val day = 3

when (day) {
    1 -> println("Понедельник")
    2 -> println("Вторник")
    3 -> println("Среда")
}
```

Вывод:
```
Среда
```

> [!NOTE]
> when - это аналог switch из Java и C++. Но в отличие от switch, писать break после каждой ветки не нужно: выполняется только одна подходящая ветка, и when сразу заканчивается

## else

else - ветка по умолчанию, выполняется, если не подошел ни один вариант
```kotlin
val day = 9

when (day) {
    1 -> println("Понедельник")
    2 -> println("Вторник")
    else -> println("Такого дня нет")
}
```

Вывод:
```
Такого дня нет
```

## Несколько строк в ветке

Если в ветке нужно сделать несколько действий, их берут в фигурные скобки
```kotlin
var score = 10

when (score) {
    10 -> {
        println("Максимальный балл")
        score *= 2
        println("Бонус: $score")
    }
    else -> println("Обычный балл")
}
```

Вывод:
```
Максимальный балл
Бонус: 20
```

## Несколько значений в одной ветке

Значения перечисляются через запятую
```kotlin
val day = 6

when (day) {
    1, 2, 3, 4, 5 -> println("Будний день")
    6, 7 -> println("Выходной")
    else -> println("Такого дня нет")
}
```

> [!WARNING]
> Несколько значений пишутся через запятую, а не через `||`. Запись `1 || 2 -> ...` не скомпилируется: `||` работает только с Boolean

## Диапазоны: in и !in

В ветке можно проверить, входит ли значение в диапазон
```kotlin
val age = 15

when (age) {
    in 0..6 -> println("Дошкольник")
    in 7..17 -> println("Школьник")
    !in 0..120 -> println("Странный возраст")
    else -> println("Взрослый")
}
```

Вывод:
```
Школьник
```

## Вычисляемые значения

И проверяемое значение, и варианты в ветках могут быть выражениями
```kotlin
val a = 10
val b = 5

when (a + b) {
    b * 3 -> println("a + b равно b * 3")   // 15 == 15
    b + 5 -> println("a + b равно b + 5")
    else -> println("Ничего не подошло")
}
```

Вывод:
```
a + b равно b * 3
```

Можно сразу объявить переменную прямо в when. Она будет видна только внутри when
```kotlin
when (val sum = a + b) {
    15 -> println("Ровно 15")
    else -> println("Сумма: $sum")
}
// здесь sum уже не существует
```

## when без значения

Если после when не писать скобки со значением, то в каждой ветке пишется полноценное условие (Boolean). Это работает как цепочка if...else if, только читается легче
```kotlin
val temperature = 25

when {
    temperature < 0 -> println("Мороз")
    temperature < 15 -> println("Прохладно")
    temperature < 30 -> println("Тепло")
    else -> println("Жара")
}
```

Вывод:
```
Тепло
```

> [!WARNING]
> Сравнения вида `> 5` можно писать только в when без значения. Если значение в скобках есть, ветка сравнивается с ним на равенство, и `x > 5 -> ...` уже не сработает так, как ожидаешь

```kotlin
val x = 10

when (x) {
    x > 5 -> println("Больше 5")   // ошибка: сравнивает x (Int) с true/false (Boolean)
}

when {
    x > 5 -> println("Больше 5")   // так правильно
}
```

> [!WARNING]
> Ветки проверяются сверху вниз, и выполняется только первая подходящая. Поэтому порядок важен, как и в if...else if: если в примере с температурой поставить `temperature < 30` первой веткой, то при -5 выведется "Тепло"

## when как выражение

when, как и if, возвращает значение. Его можно сразу записать в переменную
```kotlin
val day = 2

val dayName = when (day) {
    1 -> "Понедельник"
    2 -> "Вторник"
    3 -> "Среда"
    else -> "Неизвестно"
}

println(dayName)   // Вторник
```

С диапазонами тоже работает
```kotlin
val sum = 1000

val discount = when (sum) {
    in 0..499 -> 0
    in 500..999 -> 5
    else -> 10
}

println(discount)   // 10
```

> [!WARNING]
> Если when используется как выражение (значение куда-то записывается), то else обязателен. Иначе непонятно, какое значение получится, если ни одна ветка не подошла, и будет ошибка компиляции

Если в ветке блок из нескольких строк, значение ветки - это последняя строка блока. Правило то же, что у if (см. [Блоки в if-выражении](06-if-else.md#блоки-в-if-выражении))
```kotlin
val result = when (day) {
    2 -> {
        println("Вторник найден")
        "Вторник"            // <- значение ветки
    }
    else -> "Неизвестно"
}
```

## Когда что использовать

- **if** - когда одно-два условия или условие сложное (с `&&`, `||`)
- **when со значением** - когда одно значение сравнивается со многими вариантами
- **when без значения** - когда много разных условий подряд, вместо длинной цепочки else if
