# Циклы: for, while, do-while, break и continue

[← when](07-when.md) · [Этап 1](../README.md) · [Главная](../../README.md) · [Диапазоны →](09-ranges.md)

## Коротко

Циклы повторяют блок кода несколько раз. `for` перебирает элементы или диапазон. `while` и `do-while` повторяют, пока верно условие. `break` выходит из цикла, `continue` пропускает остаток итерации.

---

## for

Самый частый цикл — перебирает элементы коллекции или диапазон.

```kotlin
for (элемент in диапазон_или_коллекция) {
    // код выполняется для каждого элемента
}
```

Пример с диапазоном:

```kotlin
for (i in 1..5) {
    println(i) // выведет 1, 2, 3, 4, 5
}
```

Диапазон `1..5` включает оба конца. Более подробно о диапазонах — в следующей теме.

Пример с вложенным циклом — таблица умножения:

```kotlin
for (i in 1..3) {
    for (j in 1..3) {
        print("${i * j} ")
    }
    println()
}
// выведет:
// 1 2 3
// 2 4 6
// 3 6 9
```

> [!WARNING]
> `for (i in 1..5)` — это не индексный цикл. Переменная `i` сама содержит значение из диапазона, не порядковый номер. Если нужны индексы, это решается позже, когда займёмся коллекциями.

---

## while

Проверяет условие **перед** каждой итерацией. Если условие ложно с самого начала, цикл не выполнится ни разу.

```kotlin
while (условие) {
    // код выполняется, пока условие верно
}
```

Пример: вывод квадратов, пока число больше нуля.

```kotlin
var x = 5
while (x > 0) {
    println(x * x)
    x--
}
// выведет: 25, 16, 9, 4, 1
```

> [!WARNING]
> Если условие никогда не станет ложным, цикл повторяется бесконечно. Например, `while (true)` — это намеренно бесконечный цикл, из которого выходят через `break`. Ошибка: забыть изменить значение переменной в цикле: `while (x > 0) { println(x) }` без `x--` зависнет.

---

## do-while

Противоположность `while`: сначала **выполняет** блок кода, потом проверяет условие. Поэтому цикл выполнится минимум один раз, даже если условие ложно изначально.

```kotlin
do {
    // код выполняется хотя бы один раз
} while (условие)
```

Пример:

```kotlin
var x = 0
do {
    println(x)
    x++
} while (x < 3)
// выведет: 0, 1, 2
```

Хотя `x = 0 < 3`, блок выполнился один раз перед проверкой.

Второй пример — менее очевидный:

```kotlin
var x = 10
do {
    println(x)
} while (x < 5)
// выведет: 10 (один раз)
```

`do-while` редко используется. Он нужен в редких случаях, когда блок **всегда** должен выполниться хотя бы один раз (например, повторный ввод данных, пока ввод неправильный).

## continue и break

### break

Полностью завершает цикл. Выполнение переходит на строку после цикла.

```kotlin
for (i in 1..10) {
    if (i == 5) break
    println(i)
}
// выведет: 1, 2, 3, 4
```

### continue

Пропускает оставшиеся инструкции текущей итерации и переходит к следующему элементу или к проверке условия.

```kotlin
for (i in 1..5) {
    if (i == 3) continue
    println(i)
}
// выведет: 1, 2, 4, 5
```

### Вложенные циклы и метки

`break` выходит только из того цикла, в котором он вызван. Чтобы выйти из внешнего цикла, нужна **метка**.

```kotlin
outerLoop@ for (i in 1..3) {
    for (j in 1..3) {
        if (i == 2 && j == 2) break@outerLoop
        println("($i, $j)")
    }
}
// выведет:
// (1, 1)
// (1, 2)
// (1, 3)
// (2, 1)
```

Метка пишется перед циклом, потом упоминается в `break@метка` или `continue@метка`.

> [!WARNING]
> Метки сложные и редко нужны. Если код с метками становится запутанным, это сигнал переделать логику: выйти в отдельную функцию, которая вернёт `false` вместо `break@метка`. Метки лучше использовать редко и только когда действительно нет способа проще.

## Когда какой цикл использовать

- **for** — если знаешь заранее, сколько раз повторять, или перебираешь коллекцию. Например, вывести числа от 1 до 100.
- **while** — если условие выхода сложное, или не знаешь, сколько раз повторять. Например, вводить число, пока оно не будет в нужном диапазоне.
- **do-while** — очень редко. Только если блок **обязательно** должен выполниться один раз. Например, реальный сценарий: `do { число = readln().toInt() } while (число < 0)` — ввести число, потом проверить. Ввод произойдёт хотя бы один раз.

## Подвохи и частые ошибки

1. **Бесконечный while**: забыть изменить значение переменной в теле цикла.
   ```kotlin
   var x = 1
   while (x <= 10) {
       println(x)
       // x++ забыли
   }
   // зависнет
   ```

2. **Условие в while никогда не станет ложным** по логике программы.
   ```kotlin
   var x = 1
   while (x != 10) {
       x += 2
   }
   // если x нечётное, никогда не будет == 10
   ```

3. **for с диапазоном 1..5** — это не массив и не индексный доступ. Переменная содержит само значение, не номер.
   ```kotlin
   for (i in 1..5) {
       // i = 1, потом 2, потом 3... (не 0, 1, 2, 3, 4)
   }
   ```

4. **continue и break в вложенных циклах** — `break` выходит только из текущего цикла, не из всех сразу.
   ```kotlin
   for (i in 1..3) {
       for (j in 1..3) {
           if (j == 2) break
           println("($i, $j)")
       }
   }
   // выведет: (1, 1), (2, 1), (3, 1) — только выход из внутреннего цикла
   ```

5. **do-while с точкой с запятой**: синтаксис `} while (условие);` — это правильно, точка с запятой обязательна.
