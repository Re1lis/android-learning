## Коротко

Условное выражение проверяет условие и возвращает Boolean: true, если условие верно, и false, если нет.  

## Операции отношения

Сравнивают два значения и возвращают Boolean

| Оператор | Значение | Пример |
|----------|----------|--------|
| `>` | больше | `35 > 12` -> true |
| `<` | меньше | `11 < 12` -> true |
| `>=` | больше или равно | `11 >= 11` -> true |
| `<=` | меньше или равно | `15 <= 11` -> false |
| `==` | равно | `12 == 12` -> true |
| `!=` | не равно | `12 != 12` -> false |

```kotlin
val a = 11
val b = 12
println(a > b)    // false
println(a < b)    // true
println(a >= b)   // false
println(a <= b)   // true
println(a == b)   // false
println(a != b)   // true
```

Строки тоже можно сравнивать через ==, сравнивается содержимое
```kotlin
println("Kotlin" == "Kotlin")   // true
```

> [!WARNING]
> Дробные числа нельзя сравнивать через == напрямую: Double хранит числа приблизительно, и мелкая погрешность ломает точное сравнение

```kotlin
println(0.1 + 0.2 == 0.3)   // false
println(0.1 + 0.2)          // 0.30000000000000004
```

## Логические операции

Работают с Boolean, чаще всего объединяют несколько сравнений

- `and` - true, только если оба значения true
- `or` - true, если хотя бы одно значение true
- `xor` - true, если ровно одно значение true (если оба одинаковые - false)
- `!` - переворачивает значение: !true это false
- `not()` - то же самое, что `!`

```kotlin
println(true and false)             // false
println((11 >= 5) and (9 < 10))     // true

println(true or false)              // true
println((11 < 5) or (9 > 10))       // false

println(true xor false)             // true
println(true xor (90 > 10))         // false - оба true

println(!true)                      // false
println(true.not())                 // false
```

### && и ||

В реальном коде вместо and и or почти всегда пишут `&&` и `||`. Результат тот же, но они ленивые: если ответ понятен уже по левой части, правая даже не вычисляется

```kotlin
false && что_угодно   // правая часть не выполняется, результат и так false
true  || что_угодно   // правая часть не выполняется, результат и так true

false and что_угодно  // правая часть выполняется все равно
```

> [!WARNING]
> Из-за этого `&&` может спасти от ошибки:
> - `x != 0 && 10 / x > 1` - при x = 0 правая часть не выполнится, ошибки не будет
> - `x != 0 and 10 / x > 1` - при x = 0 правая часть выполнится, и будет деление на ноль
>
> Поэтому по умолчанию лучше писать `&&` и `||`

## in и !in

Проверяют, входит ли значение в диапазон

- `in` - true, если значение входит
- `!in` - true, если значение не входит

```kotlin
println(5 in 1..6)     // true
println(4 in 11..15)   // false
println(8 !in 1..6)    // true
```

> `1..6` - это числа от 1 до 6 включительно, то есть 6 тоже входит
