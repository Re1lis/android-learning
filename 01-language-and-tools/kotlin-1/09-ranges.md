# Диапазоны: .., until, step, downTo

[← Циклы](08-loops.md) · [Этап 1](../README.md) · [Главная](../../README.md) · [Массивы →](10-arrays.md)

## Коротко

Диапазон — это набор значений между двумя границами, например `1..5`. Используется в циклах `for` и для проверки `in`/`!in`. Есть четыре способа задать диапазон: `..` (по возрастанию), `downTo` (по убыванию), `until` (без верхней границы), `step` (шаг).

---

## Оператор `..`

Создаёт диапазон по возрастанию. **Обе границы включены.**

```kotlin
val range = 1..5        // 1, 2, 3, 4, 5
val letters = 'a'..'d'  // a, b, c, d
```

Мы уже видели этот оператор в циклах (тема «Циклы») и в `in`/`!in` (тема «Условные выражения»). Здесь — что он возвращает на самом деле.

> [!NOTE]
> `1..5` — это не просто синтаксис цикла, это отдельное значение типа `IntRange` (для чисел) или `CharRange` (для символов). Его можно сохранить в переменную и использовать не только в `for`.

```kotlin
val range: IntRange = 1..5
println(range) // 1..5
```

---

## Функция `downTo`

Создаёт диапазон по убыванию.

```kotlin
val countdown = 5 downTo 1 // 5, 4, 3, 2, 1

for (i in 5 downTo 1) {
    print("$i ") // 5 4 3 2 1
}
```

> [!WARNING]
> `5..1` (обычный `..` с границами в обратном порядке) **не выдаст ошибку**, но и не создаст обратный диапазон — он будет просто пустым. Для убывания обязательно нужен `downTo`.
> ```kotlin
> for (i in 5..1) {
>     println(i) // не выполнится ни разу
> }
> ```

---

## Функция `step`

Задаёт шаг, с которым идут следующие элементы. Работает и с `..`, и с `downTo`.

```kotlin
val odd = 1..10 step 2            // 1, 3, 5, 7, 9
val reversed = 10 downTo 1 step 3 // 10, 7, 4, 1
```

> [!WARNING]
> `step` всегда указывается **положительным числом**, даже в убывающем диапазоне (`downTo`). Направление задаёт `downTo`, а `step` — только величину шага.
> ```kotlin
> val wrong = 10 downTo 1 step -3 // ошибка компиляции
> val right = 10 downTo 1 step 3  // 10, 7, 4, 1 — правильно
> ```

---

## Функция `until`

Создаёт диапазон **без верхней границы**. Последнее значение — на единицу меньше указанного.

```kotlin
val a = 1 until 9        // 1, 2, 3, 4, 5, 6, 7, 8  (9 не входит)
val b = 1 until 9 step 2 // 1, 3, 5, 7
```

Чем отличается от `..`:

```kotlin
for (i in 1..5)    print("$i ")  // 1 2 3 4 5
println()
for (i in 1 until 5) print("$i ") // 1 2 3 4
```

> [!NOTE]
> `until` особенно удобен для индексов: если в коллекции 5 элементов, индексы — от 0 до 4. `0 until size` даёт ровно нужный набор, без необходимости писать `0..size - 1`. Пока у нас коллекций не было, но этот приём встретится позже.

---

## Проверка вхождения: `in` и `!in`

Диапазон можно использовать не только в цикле, но и для проверки, входит ли значение в него. Это уже встречалось в теме «Условные выражения», здесь — напоминание в контексте диапазонов:

```kotlin
val range = 1..5

println(3 in range)   // true
println(10 in range)  // false
println(6 !in range)  // true
```

---

## Диапазоны в циклах `for`

Все конструкции выше работают в `for` одинаково — диапазон просто передаётся в `in`:

```kotlin
fun main() {
    for (i in 5 downTo 1) print("$i ")   // 5 4 3 2 1
    println()

    for (c in 'a'..'d') print("$c ")     // a b c d
    println()

    for (i in 1..9 step 2) print("$i ")  // 1 3 5 7 9
    println()

    for (i in 1 until 9) print("$i ")    // 1 2 3 4 5 6 7 8
    println()
}
```

## Краткие итоги

| Конструкция | Что делает | Пример | Результат |
|---|---|---|---|
| `..` | По возрастанию, обе границы включены | `1..4` | 1 2 3 4 |
| `downTo` | По убыванию | `4 downTo 1` | 4 3 2 1 |
| `step` | Задаёт шаг (всегда положительный) | `1..7 step 3` | 1 4 7 |
| `until` | Верхняя граница не включается | `1 until 4` | 1 2 3 |
| `in` / `!in` | Проверка вхождения | `2 in 1..4` | true |

---

## Подвохи

1. **`a..b` с `a > b` не ошибка, а пустой диапазон.** Для убывания нужен `downTo`, а не перевёрнутый `..`.
2. **`step` не бывает отрицательным**, даже в `downTo`. Направление задаёт сам `downTo`/`..`, шаг — только модуль расстояния между элементами.
3. **`until` исключает верхнюю границу**, `..` включает. Легко перепутать, когда нужен ровно диапазон 1-10, а не 1-9.
4. **Диапазон — это значение**, а не просто синтаксис цикла. `val r = 1..5` компилируется и может храниться, передаваться, сравниваться.
