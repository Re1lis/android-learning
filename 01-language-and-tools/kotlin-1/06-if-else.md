# Условная конструкция if...else

[← Условные выражения](05-conditions.md) · [Этап 1](../README.md) · [Главная](../../README.md)

## Коротко

if проверяет условие и выполняет код только тогда, когда условие true. С else можно задать, что делать, если условие false. В Kotlin if еще и возвращает значение, поэтому его можно сразу записать в переменную.

## if

Если условие true - выполняется блок в фигурных скобках, если false - блок пропускается
```kotlin
val a = 10
if (a == 10) {
    println("a равно 10")
}
```

Вывод:
```
a равно 10
```

## if...else

else - то, что выполнится, если условие false
```kotlin
val a = 10
if (a == 10) {
    println("a равно 10")
} else {
    println("a НЕ равно 10")
}
```

Если в блоке всего одна строка, фигурные скобки можно не ставить
```kotlin
if (a == 10)
    println("a равно 10")
else
    println("a НЕ равно 10")
```

> [!WARNING]
> Без фигурных скобок к if относится только одна строка. Вторая выполнится всегда, даже если условие false

```kotlin
val a = 5
if (a == 10)
    println("a равно 10")
    println("Это внутри if?")   // нет! выполнится всегда, отступ ничего не значит

// Вывод: Это внутри if?
```

> Поэтому лучше всегда ставить фигурные скобки, кроме совсем коротких случаев в одну строку

## else if

Когда вариантов больше двух, используется цепочка else if. Последний else - вариант по умолчанию, если не подошло ни одно условие
```kotlin
val a = 10
if (a == 10) {
    println("a равно 10")
} else if (a == 9) {
    println("a равно 9")
} else if (a == 8) {
    println("a равно 8")
} else {
    println("a имеет неопределенное значение")
}
```

> [!WARNING]
> Условия проверяются сверху вниз, и выполняется только первая подходящая ветка. Остальные уже не проверяются, поэтому порядок важен

```kotlin
val score = 95

// неправильно: 95 >= 50 - true, до проверки на 90 дело не дойдет
if (score >= 50) {
    println("Зачет")
} else if (score >= 90) {
    println("Отлично")       // никогда не выполнится
}

// правильно: сначала более строгое условие
if (score >= 90) {
    println("Отлично")
} else if (score >= 50) {
    println("Зачет")
}
```

## if как выражение

В Kotlin if не только выполняет код, но и возвращает значение. Его можно сразу записать в переменную
```kotlin
val a = 10
val b = 20
val max = if (a > b) a else b

println(max)   // 20
```

С else if тоже работает
```kotlin
val a = 20
val b = 20
val result = if (a > b) 1 else if (a < b) -1 else 0

println(result)   // 0
```

> [!NOTE]
> В Kotlin нет тернарного оператора `условие ? a : b`, как в Java или C++. Вместо него используется if как выражение: `if (условие) a else b`

> [!WARNING]
> Если if используется как выражение (его значение куда-то записывается), то else обязателен. Иначе непонятно, какое значение будет, если условие false, и будет ошибка компиляции

```kotlin
val max = if (a > b) a              // ошибка: нет else
val max = if (a > b) a else b       // так можно
```

## Блоки в if-выражении

### Зачем это нужно

Обычное if-выражение - это когда в каждой ветке ровно одно значение:
```kotlin
val max = if (a > b) a else b
```

Но иногда перед тем, как выбрать значение, нужно сделать что-то еще: например, вывести сообщение. В одну строку это уже не помещается, поэтому ветку разворачивают в блок `{ }` и пишут внутри несколько строк

### Главное правило

> [!IMPORTANT]
> Значение блока - это его ПОСЛЕДНЯЯ строка. Все строки выше просто выполняются по очереди, а последняя становится результатом всего if и попадает в переменную

```kotlin
val a = 10
val b = 20

val max = if (a > b) {
    println("Больше a")    // просто выполняется
    a                       // <- значение ветки, попадет в max
} else {
    println("Больше b")    // просто выполняется
    b                       // <- значение ветки, попадет в max
}

println(max)
```

Как это работает по шагам при a = 10, b = 20:
1. `a > b` -> false, значит идем в else
2. выполняется `println("Больше b")` -> на экране "Больше b"
3. последняя строка блока - `b`, то есть 20 -> `max = 20`
4. ветка if не выполняется вообще, ее println не срабатывает

Вывод:
```
Больше b
20
```

### Пример из жизни

```kotlin
val price = 1000
val isMember = true

val finalPrice = if (isMember) {
    println("Скидка для участника клуба")
    price - 100        // <- значение
} else {
    println("Без скидки")
    price              // <- значение
}

println("К оплате: $finalPrice")
```

Вывод:
```
Скидка для участника клуба
К оплате: 900
```

> [!WARNING]
> Значением становится только последняя строка. Если перед ней стоит еще одно значение, оно просто вычисляется и выбрасывается - в переменную оно не попадет (IntelliJ подсветит его как неиспользуемое)

```kotlin
val x = if (5 > 3) {
    println("Первая ветка")
    100        // вычисляется и выбрасывается
    200        // <- вот это значение ветки
} else {
    300
}
println(x)
```

Вывод:
```
Первая ветка
200
```

## Подвохи

> [!WARNING]
> В условии нужно сравнение `==`, а не присваивание `=`. Kotlin не даст скомпилировать `if (a = 10)` - это ошибка, а не тихий баг, как в некоторых других языках

> [!WARNING]
> Условие в if должно быть именно Boolean. Число вместо условия не подойдет: `if (a)` при `val a = 1` - ошибка, нужно `if (a != 0)`
