# Android Notes

Конспект на пути к первой стажировке Android-разработчиком

## Как устроен конспект

- Главная страница (эта) - весь путь по этапам
- В каждом этапе своя папка с содержанием: блоки и темы
- Тема со ссылкой - пройдена, тема без ссылки - еще впереди. Первая тема без ссылки - то, что изучаю сейчас
- В каждой теме навигация: назад, вперед, к этапу и на главную
